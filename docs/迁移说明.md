# CUshop 小程序 → 网站迁移 说明

> 最后更新：2026-09-15

## 一、这是做什么

把 `mini-market`（微信小程序版 CUshop，17 页 + 10 云函数 + 12 集合）迁移成一个可部署到 Vercel 的网页版，**产品形态和视觉完全一致**。

小程序原后端锁死在微信云开发上，网页版用不了的三样东西换成通用技术栈：

| 原（微信云开发） | 新（Web） |
|---|---|
| 身份 `cloud.getWXContext().OPENID` | 用户名 + 密码 + JWT cookie session |
| 数据库云数据库 | Neon Postgres + Prisma 7 |
| 图片云存储 fileID | Cloudinary（存 https URL） |

## 二、技术选型（已确认）

- **Next.js 16** 全栈（App Router + Route Handlers + Proxy）
- **Neon Postgres + Prisma 7**（driver adapter `@prisma/adapter-neon`）
- **Cloudinary** 图片存储
- **用户名 + 密码** 登录（`jose` 签发 JWT，httpOnly cookie）
- **全量迁移** 17 个页面（含管理后台）

## 三、关键设计决策

1. **保留 `{code, data, msg}` 信封 + `action` 分发**：前端 48 处 `callCloud(fn, {action})` 调用全部收口在一个封装文件，后端不按 REST 重设计，而是原样镜像云函数结构。回报：前端调用点几乎不改，云函数里的校验/权限逻辑逐行照搬。
2. **图片直存 URL**：上传时服务端直接传 Cloudinary，最终 https 地址存库，`getTempFileURL` 中间层整个消失。
3. **身份 OPENID → cuid**：9 个集合的外键从 OPENID 换成 `users.id`，前端 `isSelf`/`isBuyer` 判断改读 session。
4. **桌面响应式**：移动优先，≥900px 时列表 1 列变多列，tabBar 改顶部导航。
5. **无 Prisma relation**：所有表纯标量字段，跨表关联手工 join（照搬原云函数逻辑），避免迁移复杂度和级联删除坑。

## 七、目录结构

```
cushop-web/
├── prisma/
│   ├── schema.prisma        # 12 张表
│   └── (migrations/)        # migrate 后生成
├── prisma7.config.ts        # Prisma 7 配置（datasource url）
├── .env                     # DATABASE_URL / SESSION_SECRET / CLOUDINARY_*
└── src/
    ├── generated/prisma/    # Prisma client（生成，勿手改）
    ├── lib/                 # prisma / jwt / session / auth / api
    ├── proxy.ts             # 路由守卫
    └── app/
        ├── api/auth/        # register/login/logout/me
        ├── login/page.tsx   # 登录注册页
        ├── page.tsx         # 首页占位
        └── globals.css      # 设计 token + 全局类
```
