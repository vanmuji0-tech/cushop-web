## 一、浏览器全闭环验收（先本地跑通，再部署）

本地启动：`npm run dev` → 打开 http://localhost:3000
（手机真机：连同一 WiFi，开 http://192.168.110.33:3000）

**准备两个浏览器**（或一个浏览器开普通 + 无痕窗口），分别登录两个账号。

### 账号 A（首个注册 → 自动成为管理员）
1. 注册 `账号A`（如 `alice` / 密码 6 位以上）

### 账号 B（普通用户）
2. 注册 `账号B`（如 `bob`）

### 商品闭环（B 发，A 看）
3. A 用「发布」发一个商品（先不传图，纯文字）→ 成功后跳广场能看到
4. B 在广场看到商品卡 → 点进详情 → 留言一条 → 收藏
5. B「我的」→ 我的收藏 / 我的留言 能看到刚才的记录
6. A「我的」→ 我的发布 能看到商品，可「下架 / 标记已卖出 / 重新上架 / 删除」

### 私聊成交（A 卖 → B 买 → 锁定成交 → 互评）
7. B 在商品详情点「私聊」→ 进入聊天页发一条消息
8. A 打开「我的 → 消息」→ 看到会话（红点）→ 点进去
9. A 点「🔒 锁定商品给买家」→ B 那边看到锁定卡 → 点「确认成交」
10. 双方看到「🎉 成交凭证」→ 点「复制凭证」验证剪贴板 → 点「评价本次交易」选「靠谱」提交
11. 商品状态变成「已卖出」；A 进卖家主页（点卖家头像）能看到「已卖出 1 / 靠谱 1」徽章

### 社群（发帖 / 盖楼 / 点赞）
12. B 进「社群」tab → 点右下角「发帖」→ 发一篇带话题的帖子
13. A 进社群看到帖子 → 点进去 → 点赞 → 回复一条 → B 再回复（盖楼）
14. 话题流切换「闲置经验」等话题能过滤

### 治理（举报 → 后台处理）
15. B 举报 A 的某条留言/商品 → 弹层选理由提交（重复举报会被拦「你已举报过」）
16. A（管理员）「我的 → 管理后台」→「举报」tab 看到举报 → 点「下架商品 / 删留言 / 忽略」
17. A 后台「统计/商品/留言/用户/评价」各 tab 正常；B 直接访问 `/admin` 显示「无权限」

### 资料 / 关于
18. A「我的 → 个人资料」改昵称/微信号/地区、换头像 → 保存 → 回到我的页已更新
19. A「我的 → 关于」看到关于页

> 传图相关（发商品带图、聊天发图、换头像）依赖 Cloudinary 密钥，未配置时会提示「未配置图片服务」——这是正常的，配好密钥后即可用。

## 二、部署前准备

### 1. 需要的密钥

| 密钥 | 用途 | 去哪拿 |
|---|---|---|
| `DATABASE_URL` | 数据库 | ✅ 已有（Neon，之前给过） |
| `SESSION_SECRET` | JWT 签名 | 自己生成（见下） |
| `CLOUDINARY_CLOUD_NAME` | 图片 | cloudinary.com 控制台 |
| `CLOUDINARY_API_KEY` | 图片 | 同上 |
| `CLOUDINARY_API_SECRET` | 图片 | 同上 |

**生成 SESSION_SECRET**（在项目目录跑）：
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```
把输出的一长串复制下来即可。

### 2. 推送到 GitHub（Vercel 从 Git 部署）

项目现在还不是 git 仓库，先初始化并推上去：

```bash
cd cushop-web
git init
git add .
git commit -m "CUshop web 迁移完成：全功能 + 部署就绪"
# 在 GitHub 新建一个空仓库 cushop-web，然后：
git remote add origin https://github.com/<你的用户名>/cushop-web.git
git push -u origin main
```

> 注意：`.gitignore` 已忽略 `.env*`（密钥不进 git）和 `/src/generated/prisma`（生成的 client）。
> `package.json` 已加 `postinstall: prisma generate`，Vercel 装依赖时会自动重新生成 client，所以 client 不必提交。

## 三、Vercel 部署

1. 打开 [vercel.com](https://vercel.com) → 用 GitHub 登录
2. **Add New → Project** → 导入刚推的 `cushop-web` 仓库
3. **Framework Preset** 选 **Next.js**（一般自动识别）
4. **Environment Variables** 填入上面 5 个密钥（`DATABASE_URL` / `SESSION_SECRET` / `CLOUDINARY_*` 三个）
5. Build Command 保持默认 `npm run build`（`postinstall` 会自动 `prisma generate`）
6. 点 **Deploy**

部署完成后 Vercel 会给你一个 `https://xxx.vercel.app` 地址，直接就能访问。

### 数据库说明
- Neon 数据库的 12 张表**已经建好**（本地 `migrate dev` 时已应用），部署后无需再迁移。
- 以后若改了 schema，先在本地 `npx prisma migrate dev --name xxx` 生成迁移，推到 git 后，在 Vercel 的 build 命令改成 `npx prisma migrate deploy && npm run build`（或本地跑 `npm run db:deploy` 指向生产库）。

### 上线后验证
- 用手机/电脑访问线上地址，注册新账号（线上首号也是 admin）
- 跑一遍上面「一」里的关键路径（发商品、私聊、发帖、举报、后台）
- 传图（需要 Cloudinary 已配好）
